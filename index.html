WILDERNESS TRAVEL

Speak naturally. Exact engine commands remain deterministic, while ordinary tabletop language is interpreted through a universal semantic Action Plan before the rules engine acts. The rules engine remains authoritative. The default Kai Besil campaign uses 1/2-mile wilderness hexes; legacy Karameikos saves retain their prior six-mile scale. The dedicated LOCAL MAP window shows only the current hex and one surrounding ring, or a compact list of known places when you are inside a settlement; you still maintain the campaign map yourself.

CAMPAIGN

Characters may be rolled 3d6 in order, entered from dice rolled at the table, or generated as a complete party. Starting money is 3d6×10 gp per adventurer and is pooled into the expedition treasury after any automatically purchased starting gear.

OPTIONS & DEVELOPER TOOLS

RULES OPTIONS

The contextual matrix is loaded only from the 52 workbook entries marked (RC). Natural monster attacks remain Rules Cyclopedia damage. Weapon Audit records RAW and Matrix damage side-by-side while applying only the selected system. Matrix melee uses one shared Close/Normal/Far state per melee. After movement resolves, carried weapons may be switched: Quick weapons keep attack order; Cumbersome weapons defer only that character's missile/melee attack. Matrix mode does not apply a blanket initiative loss merely for using a two-handed weapon. In Phase-Based Initiative, the initiative winner chooses movement order, then acts first in missile, magic, and melee.

DEVELOPER / RULES TRANSPARENCY

Debug Export: creates one JSON file containing the complete campaign/session journal, referee-only engine records, current full state, combat geometry and orders, parser/discourse traces, AI request/response diagnostics, runtime errors, and regression reports. It deliberately excludes the GAME_TOKEN and other credentials. Upload this file when reporting a difficult bug.

Regression Harness: RUN SELF-TESTS checks deterministic parser helpers, semantic-plan normalization, entity/group resolution, transactional combat plans, group movement, and melee-distance invariants without calling AI or changing the campaign. AI PARSER SMOKE TESTS are optional and use the configured referee connection to test several natural-language interpretations across combat, travel, social, and inventory play. The harness is also exposed as window.KnownWorldTestHarness for future browser/CI automation.

Developer Mode is full referee/testing transparency. It lets the referee answer any informational question and exposes loaded behind-the-screen state as well as hidden engine records: monster statistics, current HP, morale, saves, target logic, hidden exits/keyed data, encounter-distance procedure, initiative, attacks, and other referee-side decisions. It does not change the actual rules or rolls.

The name generator uses the attached character-sheet name lists. Human classes use Human names; Elf, Dwarf, and Halfling use their own lists. Choose a class first, then press GENERATE NAME as often as you like.

OPTIONAL ABILITY ADJUSTMENT

Trade 2 points from Strength, Intelligence, or Wisdom to raise a prime requisite by 1. Dexterity, Constitution, and Charisma cannot be lowered; no score may be lowered below 9.

Read Magic is included automatically; the character can memorize one 1st-level spell per day at 1st level.

QUICK PARTY GENERATOR

Quick generation uses the same 3d6-in-order characters and the class-appropriate male/female name lists. It tries to cover the four core human classes before adding other eligible classes. “Equipped” spends each adventurer’s own rolled starting gold on a legal weapon, armor where appropriate, and basic personal gear; nothing is free.

PARTY BEING FORMED

There is no party-size cap. Every player character added here receives a full XP share. Adventuring NPC retainers count as ½ share under the Mentzer BECMI campaign rule.
