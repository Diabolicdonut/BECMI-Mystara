# Current-Measure Size control — v0.4.346

Authority: the user’s 2026-10-19 contextual combat completion contract. This
supersedes the former intent-dependent Hold-at-Far and Press-at-Close gates.
It is an optional contextual procedure; pure Mentzer BECMI RAW bypasses it.

| Current opposing-pair Measure | Advantaged Size |
| --- | --- |
| Far | Larger |
| Normal | Neither |
| Close | Smaller |

Compare only the actual eligible opposing actors. The advantage is the absolute
difference in their Size ratings, capped at three. It applies independently of
both actors’ Press/Hold/Open intentions. Intention selects the winner’s otherwise
permitted outcome, rather than deciding whether a positional advantage exists.
Each contender uses its already rolled, original unmodified side-initiative d6.
Ordinary modified initiative totals and phase order remain separate. An opposed
tie retains Measure; equal intentions retain their existing common-intent path.
Later changes remain limited to one band per round, once per pair. There is no
extra die, action, damage, attack or compulsory escape contest.

Verified natural melee attackers retain the existing neutral Size-0 comparison.
The normal wolf’s canonical MON-0104 bite is now explicitly recognized for this
comparison: canonical source identity, one actual bite and exact 1d6 damage must
match. Governing catalogue provenance is Mentzer Basic p.39; the supplied
compatible Rules Cyclopedia printed p.212 (PDF p.214) independently confirms one
bite, 1d6. Missing passive attackContext alone does not turn this known bite into
an unknown attack. Explicit null/false/zero/malformed attackContext is not
overwritten; other unknown or altered attacks remain unresolved. This control-only
identification adds no anatomical reach, preferred/legal Measure, damage policy,+or weapon-calculator eligibility. Established melee Measure is not fixed distance.

The Size comparison is independent from directional weapon approach coverage.
Physically legal, verified uncovered new approaches and bounded surprise continue
to establish Measure without an opposed contest. Casting or disabled actors and
physically unusable weapons cannot supply an advantage. Unknown dice do not get
reconstructed from modified initiative totals. Each opponent pair remains
independent, including six or more physically legal opponents; there is no slot
capacity. Weapon switching retains the existing carried-weapon window and grants
no free Measure change. Ordinary withdrawal and retreat remain independent.

The 46 canonical weapon profiles, printed weapon/natural damage, source effects,
preferences, equipment economics, shields, encumbrance, ordinary initiative and
rule selections are preserved. Numeric control evidence remains in the referee
trace; player help and narration describe reach and handling without contest
formulas. Pure RAW retains its inactive saved contextual facts and damage choice.

Required evidence includes all 36 opposed d6 combinations, all nine intent pairs,
three Measures, both weapon directions, Size differences 0/1/2/3/5, spear/normal
sword/short sword/dagger against an actual source-backed wolf, a Close sidearm
switch and Open/Hold advantage, six independent opponents, surprise, unknown dice,
new contact, barriers, unusable weapons, mode isolation and old/repeat migration.
The new native gate runs eight embedded definitions and four real command cases
through pending movement choice, the existing weapon window, supported equipment
commands, actual saves and real page reloads. No production test bridge is shipped.

The original 1080-case native matrix and every earlier gate remain required.
Three historical expectation values in the 20-case native suite are updated for
the expressly superseded restrictions: a known Size-0 natural attacker can control
Far against a dagger, and a shorter natural attacker can Hold control at Close
without selecting an attack action. Case identities and all checks are retained;
there is no new grapple, passive damage or forced retreat rule. Tests establish
mechanics and persistence, not gameplay balance.

Ferocity and natural physical proximity damage remain separate later checkpoints.
